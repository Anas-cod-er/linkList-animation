# Double Linked List Animation

A Manim project that visualizes a double linked list with animated nodes, forward arrows, and backward arrows to show both next and previous pointers.

![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Manim](https://img.shields.io/badge/Manim-Animation-FF6B6B?style=for-the-badge)

## Overview

This project demonstrates a double linked list using rectangular nodes containing values such as `10`, `20`, `30`, and `40`. The animation shows:

- the forward links between nodes
- the backward links between nodes
- null nodes on both ends of the list
- a clean step-by-step style for learning data structure concepts

## Features

- Animated creation of each node
- Forward and backward arrow connections
- Visual representation of a doubly linked list
- Simple educational scene built with Manim
- Output saved automatically in the `media/` folder

## Requirements

- Python 3.10+
- Manim

## Installation

Install Manim in your environment:

```bash
pip install manim
```

If you are using a virtual environment, activate it first before installing the package.

## Run the Animation

From the project folder, run:

```bash
python -m manim -pqk -r 1920,1080 link-list.py Linklist
```

This renders the scene named `Linklist` and saves the output in the `media/` directory.

## Scene Details

The script defines a `Linklist` scene and creates:

- nodes with values `10`, `20`, `30`, `40`
- two `Null` nodes at the ends
- forward arrows connecting each node to the next one
- reverse arrows connecting each node to the previous one
- text label: `Double Link List`

## Notes

- This is a beginner-friendly example for visualizing linked list behavior in animation.
- The code is designed as a learning project for understanding data structure visuals with Manim.
